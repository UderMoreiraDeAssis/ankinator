# legacy/

Scripts de experimentação do pipeline antigo (PDF → questões via `pdf-parse` +
chunking por caracteres + Claude API), mantidos apenas como referência histórica.

O fluxo atual fica em [`../ankinator-app/`](../ankinator-app/) (extração com
OpenDataLoader + UI web) e, para uso via MCP, em [`../ankinator-mcp/`](../ankinator-mcp/).

Estes arquivos não são necessários para rodar o app novo e podem ser removidos
com segurança caso não tenham mais utilidade.
