function run(cmd: string, args: string[]): Promise<{ code: number; stdout: string; stderr: string }> {
  return new Promise((resolve) => {
    const child = spawn(cmd, args, { stdio: ['ignore', 'pipe', 'pipe'] });
    let stdout = ''; let stderr = '';
    child.stdout.on('data', (d) => (stdout += d.toString()));
    child.stderr.on('data', (d) => (stderr += d.toString()));
    child.on('error', () => resolve({ code: -1, stdout, stderr }));
    child.on('close', (code) => resolve({ code: code ?? -1, stdout, stderr }));
  });
}

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Node → Python sidecar (spawn argv) | `langchain-loader.ts` spawna o `.py` com argv-array (`spawn(py, [script, pdf, '--pages', …])`) — SEM shell, sem injection de comando. |
| Python stdout → Node (`JSON.parse`) | stdout do sidecar é parseado. Entrada não-confiável de processo externo. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-05 | Tampering / Injection | `spawn(py, args)` com `pdfPath`/`--pages`/`--password` | mitigate | Spawn é argv-array (clone de ocr-loader.ts `{ stdio:['ignore','pipe','pipe'] }`), NÃO `exec`/shell string → sem injeção de comando. `--password` não é logado. |
| T-02-06 | Tampering | `JSON.parse(stdout)` de processo externo | mitigate | Usa `JSON.parse` (NÃO `eval`/`Function`) — não executa código. `normalize` (Plano 01) faz acesso defensivo ao shape (`d.metadata.page ?? 1`). Stdout malformado → `JSON.parse` lança → propaga (D-04). |
| T-02-07 | Spoofing | `pythonBin()` aponta para interpretador arbitrário via env | accept | Env vars são definidas pelo próprio usuário (local single-user). Mesma postura de `ODL_PYTHON` já em produção. LOW. |
</threat_model>
