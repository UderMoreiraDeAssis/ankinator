| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-06 | Tampering | estágio imagem grava q.mnemonicoSvg | mitigate | Grava SOMENTE quando `sanitizarSvg(svg)` retorna não-null (fail-closed D-08); nunca o SVG cru. **BLOCKING**: gravar SVG não-sanitizado = HIGH. |

| T-04-09 | Tampering | prompt injection via q.resposta no payload do mnemônico | mitigate | `JSON.stringify` dos cards (T-03-02) — nunca interpolar conteúdo cru em template string. |
